**Adding one:** copy the header of an existing file (Status · Feature · Setup), number the steps, give each an expected result and, where useful, a _Red flag_. Add a row here and link the file from the feature's section in [`../STATUS.md`](../STATUS.md). When you report back, the status line here and in the file changes to ✅ Passed (date) or lists the failing steps.
